Cart Action Buttons — New Behavior
🖨 KOT
Save order → Print KOT → Send to kitchen. Table stays Running. No change to billing.
🧾 Bill
Print customer bill copy → Set table to Billed on live view. Does NOT settle.
💾 Save
Save order draft. Table stays Running. No print, no settle.
⏸ Hold
Park order. Table freed. Recall later from hold queue.
✅ Settle → Opens Payment Dialog
Opens the split-payment dialog (Option C style). Accepts Cash / UPI / Card amounts with running balance. Settle only when total ≥ bill or "Mark Due" is chosen. Frees table after.

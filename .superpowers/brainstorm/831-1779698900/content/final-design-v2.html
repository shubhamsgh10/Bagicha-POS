What gets built:

📄 Bill changes
  • Logo from NV Flash (ESC/POS command)
  • Multi-line centered address
  • Name: ___ field
  • DD/MM/YY date format
  • Cashier name (from logged-in user)
  • 4-col table: Item | Qty | Price | Amt
  • CGST X% + SGST X% split
  • Round off line
  • Grand Total bold
🍳 KOT changes
  • TABLE - N in double-size bold
  • TAKEAWAY for non-table orders
  • KOT# + date + time on one line
  • [ 02 ] quantity bracket format
  • >> modifier indent below item
  • ==== borders top + bottom
  • Total Items centered at bottom

How logo printing works on your TVS RP 3160 Gold:

Option A (Logo Top):

  • Logo stored in printer's 120KB NV Flash
  • One-time setup: upload via TVS utility tool
  • Printed with a single ESC/POS command
  • Fast, zero CPU overhead per print
  • Best quality — recommended

Option B (Logo + Text side-by-side):

  • Server converts logo PNG → raster bitmap
  • Uses jimp package (no install needed — pure JS)
  • Logo + text combined into one image block
  • Slightly slower per print (image conversion)
  • Works automatically — no printer setup needed

# App icons

Generated from `client/public/bagicha-logo.svg`.

```bash
npm run icons
```

Outputs:

- `icon.png` — 512×512 (window icon, Linux, macOS source)
- `icon@2x.png` — 1024×1024
- `icon.ico` — Windows installer / taskbar

Commit these files after changing the logo so CI and other machines can package without running the script.
